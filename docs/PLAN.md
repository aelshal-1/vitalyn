# Vitalyn — خطة المشروع

> تطبيق صحة شخصي على **iPhone + iPad + Apple Watch** (مع Widgets)، بيستخدم **Claude API** كمدرب تغذية ورياضة بيتابعك يوم بيوم.
> المرحلة الأولى: استخدام شخصي فقط.

---

## 1. الفكرة في سطر

ترفع InBody ← التطبيق يفهم جسمك ويحسب احتياجك (سعرات + ماكروز) ← تصوّر أكلك ومنتجاتك ← يسجل ويتابع ← Claude يحلل ويقترح أكل ورياضة ويعدّل الخطة كل يوم ← تشوف تقدمك (أرقام + شكل 3D) وتشاركه مع صحابك.

---

## 2. الميزات (مرتبة في Modules)

### A. الملف الصحي (Profile)
- بيانات أساسية: السن، الطول، النوع، مستوى النشاط، الهدف (خسارة وزن بمعدل كام في الأسبوع).
- **الأمراض المزمنة** والأدوية والحساسية (مثلاً: سكر، ضغط، غدة، كوليسترول...).
  - دي بتدخل في **كل** طلب لـ Claude كـ context ثابت، عشان الاقتراحات تكون آمنة (مثلاً: لو سكر ← تركيز على الكارب والـ GI، لو ضغط ← الصوديوم).
  - تنبيه واضح في التطبيق إن ده مش بديل عن الدكتور.
- تفضيلات الأكل: أكلات مصرية/أكلات مش بتحبها/ميزانية/صيام.

### B. InBody
- ترفع **صورة أو PDF** لورقة الـ InBody ← Claude (Vision + Structured Output) يستخرج:
  الوزن، Skeletal Muscle Mass، Body Fat Mass، PBF، Visceral Fat، BMR، ECW/TBW، والتحليل الجزئي (ذراعين/رجلين/جذع).
- شاشة مراجعة: تشوف القيم المستخرجة وتصحح أي رقم قبل الحفظ.
- كل InBody جديد يتسجل ← رسوم بيانية للتغير مع الوقت + مقارنة بين أي اتنين.
- كتابة الوزن ونسبة الدهون والـ Lean Mass في Apple Health.

### C. الاحتياج اليومي (Targets)
- **الحسابات تتعمل بالكود مش بالـ AI** (عشان تبقى ثابتة ومضمونة):
  - BMR من InBody (أو Katch-McArdle من الـ Lean Body Mass).
  - TDEE = BMR × معامل النشاط (يتحدث تلقائياً من بيانات Apple Health الفعلية).
  - عجز سعرات آمن (حوالي 0.5–1% من الوزن في الأسبوع).
  - بروتين حسب الـ Lean Mass، والباقي كارب/دهون — مع تعديلات حسب المرض المزمن.
- Claude بيشرح الأرقام ويقترح تعديلات، وإنت بتوافق.

### D. تسجيل الأكل بالصور
- تصوّر الطبق ← Claude يتعرف على المكونات ويقدّر الكمية ← سعرات + ماكروز + درجة ثقة.
- لو في منتج من "مكتبة المنتجات" ظاهر في الصورة ← يستخدم بياناته الدقيقة بدل التقدير.
- لو مش متأكد ← **يسألك** (مثلاً: "الرز ده كام كوباية؟" أو "ده زبادي جهينة ولا المراعي؟").
- تقدر تعدل أي حاجة قبل الحفظ. تسجيل بالكتابة أو بالصوت كمان ("أكلت 2 بيض وعيش بلدي").

### E. مكتبة المنتجات (ذاكرة المنتجات)
- تصوّر **الواجهة + جدول القيم الغذائية + الباركود** ← يتحفظ المنتج (لكل 100 جم + حجم الحصة).
- التعرف بعدين:
  1. **الباركود** (الأدق) — مسح بالكاميرا.
  2. صورة المنتج ← مطابقة مع المكتبة.
  3. لو مفيش تطابق أكيد ← يسألك يختار من أقرب منتجات.
- Open Food Facts كمصدر احتياطي للباركود لو المنتج مش في مكتبتك.

### F. جدول الأكل الأسبوعي
- Claude يعمل جدول 7 أيام ملتزم بالسعرات والماكروز والمرض المزمن وتفضيلاتك.
- التخصيص بـ 3 طرق:
  - **Presets**: (High Protein، أكل بيتي مصري، اقتصادي، صيام متقطع، رمضان، Low Carb...).
  - **كتابة** (Chat).
  - **صوت** (Voice chat: تحويل الكلام لنص على الجهاز ← Claude ← رد مكتوب/مسموع).
- تبديل وجبة بوجبة بنفس الماكروز، وقائمة مشتريات (Grocery list) تلقائية.

### G. النشاط والرياضة
- **Apple Health (قراءة)**: الخطوات، السعرات النشطة، التمارين، النبض، النوم، الوزن.
- **تسجيل يدوي بالكلام**: "لعبت كورة ساعة" ← Claude يحولها لتمرين بسعرات تقديرية ← يتكتب في Apple Health.
- **ترشيح تمارين**: Claude يعمل خطة تمارين مناسبة لحالتك ومرضك ومستواك.
- **ترشيح فيديوهات**: عن طريق YouTube Data API (Claude يحدد نوع التمرين ← البحث يرجع فيديوهات حقيقية).

### H. المدرب اليومي (Daily Coach)
- ملخص الصبح: هدف النهارده + الوجبات المقترحة.
- متابعة خلال اليوم: باقي كام سعرة/بروتين، اقتراح وجبة تكمّل اليوم.
- مراجعة آخر اليوم وأسبوعياً: إيه اللي اتعمل، إيه اللي يتعدل.
- Notifications ذكية (مش مزعجة).

### I. الأفاتار 3D (شكل إنسان حقيقي بوشّك وجسمك)
- **الوش**: 3 سيلفي (قدام/يمين/شمال) ← وش واقعي بملامحك. الآيفون 13 Pro فيه كاميرا TrueDepth بتدّي عمق للوش وده بيحسّن الدقة.
- **الجسم**: صورتين لجسمك (قدام/جنب) + أرقام InBody (الطول، الوزن، الدهون، العضلات، التوزيع الجزئي) ← شكل جسمك الحقيقي.
- **العرض**: RealityKit — لف 360°، زووم، أمام/جنب/ضهر، ومقاسات (صدر/وسط/دهون/وزن) على المجسم.
- **الرحلة**: slider من أول قياس ← دلوقتي ← الهدف، والجسم بيتغير تدريجياً (blend shapes).
- **التخصيص**: اللبس والشعر.
- **التنفيذ**: هنقارن قبل ما نبدأ المرحلة دي بين:
  1. خدمة جاهزة لإنشاء أفاتار واقعي من صور (أسرع وأدق في الوش، غالباً باشتراك).
  2. Scan بالـ LiDAR/TrueDepth على الجهاز (مجاني بس أصعب في التنفيذ ومحتاج حد يصورك).
- الصور بتتمسح في أي وقت من الإعدادات.

### J. المشاركة والإنجازات
- إنجازات (Badges): أول 5 كيلو، 7 أيام التزام، أعلى خطوات، إلخ.
- **Share card** كصورة جميلة (قبل/بعد، رسم بياني، الـ 3D) ← تشاركها في أي تطبيق.
- لاحقاً: صحاب داخل التطبيق ولوحة منافسة (محتاجة Backend).

### K. Widgets + Apple Watch
- **Widgets على iPhone/iPad** (Home + Lock Screen):
  - السعرات الباقية + حلقات الماكروز.
  - منحنى الوزن.
  - الخطوات vs الهدف.
  - Interactive: تسجيل مياه/وجبة preset بضغطة.
- **Apple Watch**:
  - ملخص اليوم (سعرات/ماكروز/خطوات).
  - تسجيل سريع (مياه، وزن، وجبة preset، أو بالـ Dictation).
  - Complications على الـ Watch face.
- **iPad**: نفس التطبيق بتصميم Split View وشاشات أوسع للرسوم البيانية والجدول الأسبوعي.

## 3. التقنيات (Tech Stack)

| الجزء | التقنية |
|---|---|
| اللغة والواجهة | Swift 6 + SwiftUI (كود واحد لـ iPhone/iPad/Watch) |
| التخزين | SwiftData محلي + مزامنة CloudKit (Private DB) بين أجهزتك |
| مشاركة البيانات مع Widgets/Watch | App Group + WatchConnectivity |
| Apple Health | HealthKit |
| Widgets/Complications | WidgetKit + App Intents |
| الرسوم البيانية | Swift Charts |
| 3D | RealityKit (Model بـ Blend shapes بتتحكم فيها أرقام InBody) |
| الكاميرا/الباركود | VisionKit (DataScanner) + PhotosPicker |
| الصوت | Speech framework (تحويل كلام لنص على الجهاز) + AVSpeechSynthesizer |
| الذكاء الاصطناعي | Claude API (Messages API عبر HTTP مباشر — مفيش Swift SDK رسمي) |
| فيديوهات | YouTube Data API |
| اللغات | عربي + إنجليزي مع دعم RTL |

### Claude API — إزاي هنستخدمه
- **الموديل الافتراضي**: `claude-opus-5-5` (يدعم الصور والـ PDF، $4 / $20 لكل مليون توكن input/output).
  - لو عايز توفر: `claude-sonnet-5-5` ($2 / $10) أو `claude-haiku-5-5` للمهام البسيطة.
  - هنخلي الموديل قابل للتغيير من الإعدادات لكل نوع مهمة.
- **Structured Outputs** (`output_config.format` بـ JSON Schema): لاستخراج InBody، تحليل الوجبات، جداول المنتجات ← الرد دايماً JSON مضبوط نقدر نحفظه.
- **Prompt Caching**: الملف الصحي + التعليمات الثابتة في أول الـ prompt ← تكلفة أقل وسرعة أعلى.
- **Tool use** في الشات: Claude يقدر "يسجل وجبة"، "يدور في مكتبة المنتجات"، "يعدّل الجدول"، "يقرأ خطوات النهارده" — والتطبيق ينفذ.
- **التكلفة التقديرية** (استخدام شخصي): تقريباً 2–4 سنت لكل تحليل صورة ← حوالي **5–15 دولار في الشهر** حسب الاستخدام والموديل.
- **مفتاح الـ API**: في المرحلة الشخصية يتحط في الإعدادات ويتخزن في **Keychain** (مش في الكود ولا GitHub). قبل ما التطبيق يتفتح لناس تانية ← Backend صغير (Cloudflare Worker مثلاً) يحمي المفتاح.

## 4. التطوير من غير Mac (عن طريق GitHub)

إنت عندك Apple Developer account ومعندكش Mac — ده ممكن كالتالي:

```
الكود على GitHub
   │  push
   ▼
GitHub Actions (macOS runner عليه Xcode)
   │  XcodeGen يولّد المشروع ← Build ← Sign ← Archive
   ▼
TestFlight (App Store Connect)
   │
   ▼
iPhone + iPad (تطبيق TestFlight)   ←→   Apple Watch (يتنزل تلقائي مع تطبيق الآيفون)
```

- **XcodeGen**: المشروع بيتوصف في ملف `project.yml` نصي بدل ملف Xcode المعقد ← نقدر نعدله من غير Mac.
- **التوقيع (Signing)**: بـ App Store Connect API Key ← Xcode على السيرفر يعمل الـ certificates والـ profiles أوتوماتيك.
- **الرفع**: كل push على branch معين ← build جديد يوصل TestFlight في حوالي 15–30 دقيقة.

### حدود لازم تعرفها
- **مفيش Simulator ولا Preview** عندك ← كل تجربة لازم تبقى على جهازك الحقيقي عبر TestFlight. هنعوّض بـ:
  - Unit tests بتشتغل على GitHub Actions.
  - Logs داخل التطبيق (شاشة Debug) عشان نشوف المشاكل.
- **دقائق macOS على GitHub**: لو الـ repo **Private**، الخطة المجانية ≈ 200 دقيقة macOS في الشهر (حوالي 10 builds بس). لو **Public** ← مجاني بدون حد. البديل: **Xcode Cloud** (25 ساعة مجاناً مع اشتراك الـ Developer).
- لو احتجنا Debug صعب: ممكن تأجير Mac سحابي بالساعة (MacinCloud / AWS EC2 Mac) وقت الحاجة بس.

### المطلوب منك (مرة واحدة)
1. **App Store Connect API Key** (Users and Access ← Integrations ← Keys) بصلاحية App Manager: هتحتاج `Key ID` و `Issuer ID` وملف `.p8`.
2. **إنشاء الـ App** في App Store Connect بالاسم Vitalyn و Bundle ID (مثلاً `com.<اسمك>.vitalyn`).
3. **Team ID** بتاعك من developer.apple.com.
4. إضافة دول كـ **GitHub Secrets** في الـ repo (هشرحلك خطوة بخطوة وقتها).
5. **Anthropic API Key** من console.anthropic.com (هيتحط في التطبيق نفسه، مش GitHub).
6. تنزيل تطبيق **TestFlight** على الآيفون والآيباد.

## 5. خطة التنفيذ (Roadmap)

كل مرحلة بتطلع نسخة شغالة على TestFlight تقدر تستخدمها فعلاً.

| المرحلة | المحتوى | النتيجة |
|---|---|---|
| **0. البنية التحتية** | XcodeGen + Targets (iOS/iPadOS، watchOS، Widgets) + GitHub Actions ← TestFlight | تطبيق فاضي بيتنزل على أجهزتك — ده أهم خطوة لأنها بتثبت إن الطريق من غير Mac شغال |
| **1. الأساس + InBody** | الملف الصحي والأمراض المزمنة، رفع InBody وتحليله، حساب السعرات والماكروز، ربط Apple Health، Dashboard | تعرف وضعك الحالي واحتياجك اليومي |
| **2. تسجيل الأكل** | تصوير الوجبات، مكتبة المنتجات + الباركود، سجل يومي، كتابة/صوت | بتتابع أكلك يوم بيوم |
| **3. المدرب الذكي** | شات (كتابة/صوت) مع Claude، الجدول الأسبوعي + Presets، خطة تمارين + فيديوهات، تسجيل الرياضة، ملخص يومي/أسبوعي | Claude بيتابعك ويقترح |
| **4. Widgets + Watch** | Widgets iPhone/iPad/Lock screen، تطبيق الساعة، Complications | كل حاجة قدامك من غير ما تفتح التطبيق |
| **5. الـ 3D** | Avatar من بيانات InBody، تخصيص، مقارنة حالي/هدف | تشوف شكلك بيتغير |
| **6. المشاركة** | إنجازات، Share cards | تشارك صحابك |
| **لاحقاً** | Backend لحماية المفتاح، حسابات صحاب، نشر على App Store | لو حبيت تفتحه لناس تانية |

## 6. شكل البيانات (Data Model) — مبدئي

- `UserProfile` — البيانات الأساسية، الأهداف، التفضيلات.
- `HealthCondition` — المرض، التفاصيل، الأدوية.
- `InBodyScan` — التاريخ، كل القيم، الصورة الأصلية.
- `DailyTarget` — السعرات/البروتين/الكارب/الدهون لكل يوم (بيتحسب).
- `FoodProduct` — الاسم، البراند، الباركود، القيم لكل 100 جم، حجم الحصة، الصور.
- `MealEntry` — الوقت، الصورة، العناصر (`FoodItem`: منتج أو تقدير + الكمية + الماكروز)، المصدر (صورة/كتابة/صوت).
- `MealPlan` / `PlannedMeal` — الجدول الأسبوعي.
- `WorkoutEntry` — النوع، المدة، السعرات، المصدر (Health/يدوي).
- `CoachMessage` — تاريخ الشات مع Claude.
- `Achievement` — الإنجازات.
- `AvatarSettings` — تخصيص الـ 3D.

## 7. قرارات اتاخدت

- **الأجهزة**: iPhone 13 Pro (390×844) + iPad 8 (810×1080). مفيش ساعة حالياً ← تطبيق الـ Watch يتأجل لآخر الخطة، بس الكود هيكون جاهز له.
- **أقل إصدار**: iOS / iPadOS 18.
- **الـ repo**: Public ← دقائق GitHub Actions على macOS مجانية من غير حد.
- **اللغة**: عربي وإنجليزي **مع بعض في نفس الشاشة** — كل عنوان وزرار مكتوب عربي وتحته إنجليزي (الاتجاه RTL).
- **Bundle ID**: `com.elshal.vitalyn`.
- **InBody**: هنجرب الاستخراج أول ما يبقى عندك قياس.
- **التصميم**: اتعمل على Claude Design (Canvas) قبل الكود — 12 شاشة + Widgets + iPad (الجولة التانية: باللغتين، أفاتار واقعي، Widgets جديدة).

## 8. أسئلة لسه مفتوحة

1. **المرض المزمن**: مش لازم دلوقتي، بس لو قلتلي من الأول هنظبط الشاشات والحسابات على أساسه (مثلاً: السكر محتاج متابعة جلوكوز من Apple Health).
2. **ملاحظاتك على التصميم** قبل ما نبدأ الكود.
