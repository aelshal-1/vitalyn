# تجربة Vitalyn على الموبايل

بعد ما تخلّص [SETUP.md](SETUP.md) وتنزّل التطبيق من TestFlight، جرّب بالترتيب ده:

## 1. البداية
- [ ] افتح التطبيق ← اكتب بياناتك (الاسم، السن، الطول، الوزن).
- [ ] اختار هدفك ومعدل النزول ونشاطك.
- [ ] اختار المرض المزمن والأدوية والحساسية.
- [ ] دوس **اربط Apple Health** ووافق على كل الصلاحيات.
- [ ] حط مفتاح Claude API (من [console.anthropic.com](https://console.anthropic.com) ← API Keys).
- [ ] تأكد إن "احتياجك اليومي" ظهر بسعرات وماكروز منطقية.

## 2. InBody
- [ ] التقدم ← InBody ← ضيف InBody جديد ← صوّر الورقة أو ارفع PDF ← حلّل.
- [ ] راجع الأرقام (الأصفر = Claude مش متأكد منه) وصلّح لو محتاج ← احفظ.
- [ ] ارجع لـ "اليوم": الهدف المفروض اتحدث حسب الـ BMR بتاع InBody.
- [ ] افتح Apple Health ← الوزن ونسبة الدهون اتسجلوا.

## 3. الأكل
- [ ] صوّر وجبة ← حلّل ← غيّر الجرامات بـ + و − ← جاوب على سؤال Claude لو سأل ← احفظ.
- [ ] الأكل ← اكتب أو قول ← "2 بيض وعيش بلدي وجبنة قريش" (جرّب المايك بالمصري).
- [ ] منتجاتي ← صوّر الليبل (الواجهة + جدول القيم) ← راجع ← احفظ.
- [ ] امسح باركود منتج (منتج محفوظ ← يسجله على طول، منتج جديد ← يدوّر أونلاين أو يطلب صورة الليبل).
- [ ] صوّر وجبة فيها المنتج المحفوظ ← لازم يتعرف عليه (علامة ✓ جنب الصنف).

## 4. الجدول الأسبوعي
- [ ] الأكل ← الجدول ← اختار نوع (مثلاً أكل بيتي مصري) ← اعمل جدول الأسبوع (بياخد حوالي دقيقة).
- [ ] بدّل وجبة ← قائمة المشتريات ← سجّل وجبة من الجدول.

## 5. المدرب
- [ ] اكتب "لعبت كورة ساعة النهارده" ← لازم يسجل التمرين في Apple Health.
- [ ] "شربت كوبايتين مية" ← المية تزيد.
- [ ] "اقترحلي تمرين في البيت" ← يطلع فيديوهات YouTube.
- [ ] جرّب وضع **صوت**: دوس المايك واتكلم ← دوس تاني ← الرد بيتقري بصوت عالي.

## 6. النشاط والتقدم
- [ ] التقدم ← النشاط: الخطوات (أسبوع / شهر)، سجّل تمرين يدوي، "اقترح".
- [ ] التقدم ← جسمي 3D ← صور جديدة (3 سيلفي + صورتين للجسم) ← slider الرحلة.
- [ ] التقدم ← الإنجازات ← غيّر شكل الكارت ← شارك.

## 7. الـ Widgets
- [ ] على الـ Home screen: دوس مطوّل ← + ← Vitalyn ← ضيف "سعرات وماكروز" و"مية" و"رحلتي".
- [ ] دوس **+ كوباية** في widget المية من غير ما تفتح التطبيق.
- [ ] شاشة القفل: Customize ← ضيف widget السعرات.

## 8. الآيباد
- [ ] نفس التطبيق بـ sidebar على الجنب. (البيانات حالياً منفصلة بين الآيفون والآيباد — المزامنة بـ iCloud خطوة جاية.)
